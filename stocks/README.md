# 科技股買賣區間儀表板（台股・美股）

在自己電腦上跑的中長期看盤工具：把名單裡的台股／美股科技股與 ETF（0050、0056、00878、台積電、聯發科、QQQ、NVDA…）標出**現在的價格落在自己長期區間的哪裡**（便宜／合理／偏貴），用三把尺——五線譜、年線乖離、本益比河流圖——畫出對應的價格帶，並告訴你**歷史上從這個位置出發，之後 3／6／12 個月漲的機率和幅度**。同時監測投資人會看的資訊：新聞、美國國會議員的股票申報、公司內部人買賣（美 Form 4、台董監申報）、台股三大法人與月營收、總經與 FOMC 日程。

- **只做買進／賣出，不放空、不用槓桿**；適合以月為單位的決策，不是短線。
- **規則都經過回測**（兩個市場、2000–2026、含全市場的存活偏差對照）；哪些有用、哪些沒用寫在 [docs/RESEARCH.md](docs/RESEARCH.md)，畫面裡按「回測怎麼說」也看得到。
- **誠實版的「預測」**：不給點位，給歷史條件機率與區間。對 3–12 個月報酬，任何方法的解釋力都只有幾個百分點。
- 完全免費、不需要 API 金鑰（FinMind 免費註冊可選，提高台股法人資料額度）。
- 和黃金儀表板同一套做法：本機 FastAPI＋網頁，資料全部存在本機。

## 快速開始

1. 安裝 Python 3.10 以上：<https://www.python.org/downloads/>（Windows 記得勾 **Add Python to PATH**）。
2. 下載整個 Invest 專案（Code → Download ZIP 或 `git clone`），進入 `stocks/` 資料夾。
3. 啟動：
   - **Windows**：雙擊 `start_windows.bat`
   - **macOS**：雙擊 `start_mac.command`
   - 其他：`python run.py`
4. 瀏覽器會自動打開 <http://127.0.0.1:8801>。第一次會從 Yahoo 下載名單裡每檔的歷史（約 1–2 分鐘），之後有快取；抓不到的標的會用內建的歷史（到 2026/11）。
5. 想先看畫面、不連網：`python run.py --offline`（只用內建歷史與國會交易資料）。
6. 右上角 **設定**：改名單（台股代號如 `2345`、上櫃 `3529.TWO`；美股 `TTD`）、開關防守模式、提醒、FinMind token、SEC 聯絡資訊。

### 為什麼不是「趨勢向上就看多」？

我們用 36 檔台股、35 檔美股（2000–2026）、再用 1,548 檔台股全市場與 1,247 檔 S&P 500 歷史成分股驗證：**「很便宜」區（五線譜 −2σ 以下）之後 12 個月平均多賺台股 +19～22、美股 +3～8 個百分點**，是唯一兩個市場、三段期間都站得住的訊號；台股本益比河流圖兩端都有用（最低 25% 買 +20、最高 10% 買 −15）。但**「偏貴就賣」不成立**（美股年線乖離很貴區之後 12 個月反而多賺 10 個百分點），**趨勢向上之後的報酬反而較低**。所有把區間當進出場規則（出區間就空手）的做法，年化都輸買進持有 3–11 個百分點；10 月均線是唯一值得保留的風險工具（回撤少 25–50%，代價每年 2–6 個百分點）。完整數字見 [docs/RESEARCH.md](docs/RESEARCH.md)，文獻整理見 [docs/EVIDENCE.md](docs/EVIDENCE.md)，資料來源見 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。

## 專案結構

```
run.py                     啟動（--offline 只用內建歷史；--market TW 只看台股）
stocksignal/
  universe.py              預設名單（台股 36 檔、美股 37 檔）
  zones.py                 五線譜、年線乖離、本益比河流圖
  regime.py                趨勢票數、方向文字、機率雲
  analysis.py              每檔的完整分析與建議文字
  backtest.py              長多模擬器（台股稅費）、定期定額、條件報酬
  engine.py                資料更新、分析、提醒
  server.py                FastAPI
  data/prices.py           Yahoo / yfinance / Stooq
  data/twse.py             證交所 OpenAPI、FinMind
  data/sec.py              SEC companyfacts、Form 4、OpenInsider
  data/congress.py         國會交易資料集
  data/news.py             新聞 RSS／鉅亨網、情緒標記
  data/macro.py            FRED、FOMC、月營收截止日、財報日
web/                       介面（Lightweight Charts）
research/                  回測腳本（build_data、zone_study、broad_universe、plans_study、rotation_study）
results/                   回測輸出與 research_summary.json（儀表板讀取）
data/daily/                內建歷史（.csv.gz）；data/congress_seed.csv.gz 國會交易 2014–2026
docs/                      RESEARCH.md、EVIDENCE.md、DATA_SOURCES.md
tests/                     單元測試（不偷看未來、模擬器成本、解析器、離線流程）
```

開發者：`pip install -r requirements-dev.txt && python -m pytest -q`。重跑回測：`python research/build_data.py --datasets <資料夾>` → `zone_study.py --market TW/US` → `broad_universe.py` → `plans_study.py` → `rotation_study.py` → `scripts/make_research_summary.py`。
